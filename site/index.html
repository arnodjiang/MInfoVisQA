Score provenance & how to read the leaderboard

All 25 models and 675 score cells are synchronized with the current manuscript main table. The table uses exact matching followed by text-only GPT-6 Astra judging for non-matches. Scores are author-reported; this website does not independently rerun the evaluations. View the frozen source table.

Reported scores and the original AVG are preserved at one decimal. AVG weights all 70 configurations; it is not the mean of the 26 visible XQA/LQA columns. LQA mean is computed from the 24 displayed language scores. Model grouping follows the paper; open weights does not imply these runs were self-hosted. Official model links are shown where previously documented.

Ranks use the reported overall AVG; tied scores share a rank. Language variants share the same seed question, so 8,960 configurations do not represent 8,960 independent questions.

04 / EVALUATION DESIGN

70 configurations.
One consistent protocol.

For each base QA, the visual language changes while the task stays linked to the same source. Question and answer always share a language.

The language configuration map

24 × 24

1

Read the visual

Each input contains a localized image and question. Original external prose, when required, is translated into the question language using Google Translate API. Tables are never replaced by text transcriptions.

2

Match, then judge

Exact answer matches are accepted. Other completed answers go to a text-only equivalence judge. The judge receives no image; unconfirmed equivalence counts as incorrect.

3

Aggregate every configuration

Each XQA column averages 23 visual languages. Each LQA column evaluates a single aligned language. AVG gives equal weight to all 70 configurations.

AVG = (23 × XQAZH + 23 × XQAEN + Σ LQAℓ) / 70
